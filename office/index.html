How to make your key (2 minutes, once)
  1. Open GitHub → new fine-grained token, signed in as you.
  2. Name: Office. Expiration: 1 year.
  3. Repository access: Only select repositories → ai-hq-agency.
  4. Permissions → Repository → Contents: Read-only. Nothing else.
  5. Generate token, copy it and paste it above.

The key can only read the bots' reports. It stays on this device and goes only to GitHub. Lost a phone? Delete the key on GitHub and make a new one.
