## Format, once there is something to write

```
### <Rule stated as an instruction someone can follow>
Evidence: <n> observations · <metric> vs <baseline> · first seen <date>
Applies to: <sector / touch / tier>
```

Example of what a real entry will look like:

```
### Guesthouses: lead with the Booking.com commission figure, not the tourist-volume stat.
Evidence: 9 observations · 7 replied (78%) vs 2/11 (18%) on the generic hook · since 2026-09
Applies to: Guesthouse / Rental, first touch
```
