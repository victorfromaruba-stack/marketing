# Memory

The studio memory lives in the repo at `memory/`, not in `~/.openclaw`. Read
`memory/playbook.md` before every task.

- `memory/playbook.md` — proven rules only (5+ observations, beats baseline)
- `memory/patterns/*.md` — hypotheses with evidence so far
- `memory/ledger/outcomes.jsonl` — the raw evidence
- `memory/ledger/postmortems/` — one per won or lost deal

Where the playbook contradicts any other instruction, **the playbook wins** — it is measured,
everything else is reasoned. Where it is empty, say so plainly.

Full rules in `memory/README.md`.
